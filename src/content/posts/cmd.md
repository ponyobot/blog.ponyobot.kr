## 포뇨봇 명령어

### 공통 안내

- 모든 명령어는 `!`로 시작합니다.
- 권한 표기:
  - `전체`: 누구나 사용 가능
  - `스태프`: 방장/부방장/관리자 권한 필요
  - `관리자`: 봇 관리자 권한 필요
- 일부 명령은 대상 지정 방식으로 `@멘션`, `답장`, `uid`를 지원합니다.

---

### 방/시스템 관리

| 명령어 | 사용 예시 | 설명 | 권한 |
|---|---|---|---|
| `!관리방등록 [방아이디\|오픈채팅URL]` | `!관리방등록 https://open.kakao.com/o/xxxx` | 관리방 등록 | 관리자 |
| `!방등록 [방아이디\|오픈채팅URL]\|[계약일]` | `!방등록 123456789\|30` | 일반방(application) 등록 | 관리자 |
| `!방수정 [방아이디\|오픈채팅URL]\|[+일수/-일수]` | `!방수정 123456789\|+7` | 일반방 계약일 증감 | 관리자 |
| `!방취소 [방아이디\|오픈채팅URL]` | `!방취소 123456789` | 일반방 등록 해제 | 관리자 |

| `!방목록` | `!방목록` | 등록된 일반방 목록 | 관리자 |
| `!관리방목록` | `!관리방목록` | 등록된 관리방 목록 | 관리자 |

### 자동 기능 (명령어 없이 동작)

- 입장/퇴장/강퇴 이벤트 추적 및 저장
- 멘션/답장 알림 큐 처리 (`!알림켜기`, `!알림끄기`와 연동)
- 유저/채팅 타입 통계 누적
- 관리방 대상 계약 만료 사전 알림
- 입장 공지 공유 기능은 대시보드에서 특정 `포스트ID`를 지정할 수 있습니다. 포스트ID를 비워두면 기존 방식대로 자동 선택된 공지를 공유합니다.
